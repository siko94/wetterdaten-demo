# Wetterdaten-Demo

Beispielcode für die Arbeit mit Wetterdaten aus dem [OpenData-Angebot](https://opendata.dwd.de/climate_environment/CDC/observations_germany/climate/) des Deutschen Wetterdienstes (DWD).

`hitzetage.R` erstellt ein Diagramm mit der Zahl der Tage mit 30 Grad oder mehr pro Jahr seit 1961.

`normalbereich.R` erstellt ein Diagramm, das die aktuellen Temperaturen mit denen vergleicht, die von 1961-1990 an den selben Tagen normal waren.

Benutzte R-Packages:

- [tidyverse](https://www.tidyverse.org/)
- [rdwd](https://bookdown.org/brry/rdwd/)
- [DatawRappr](https://github.com/munichrocker/DatawRappr/tree/v1.2)
